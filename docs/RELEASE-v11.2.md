# v11.2 · Git源宝审稿室

本次同步网页版源码与Windows x64安装版。发布版本v11.2、评分规则v11、上游版本0.14.1互相独立。

- Git源宝墨镜猫品牌、浅色纸面与黄蓝红强调；开始页以稿件、附件、开始审稿为主，高级配置和角色管理按需展开。
- 主编先给结论，右上角红笔式最终十分制总分；保留五团对比、真实各轮变化、完整报告章节导航、阶段卡片和评分依据。
- 完播曲线依据正文分段及各团已有有效分项/引文自动生成，考虑开头、衔接、内容兑现与商业融合，没有手填参数。
- 点击曲线、按Enter或用下拉选择节点，可查看原段、前后段、评审理由、全文相关解释；本段直接依据与全文参考明确分开。
- 不把综合稿面分直接换算完播率；重复意见不按条数叠加，商业不适用不增加阻力，单独品牌名不视为广告。
- 安装器、启动器和服务图标使用墨镜猫，安装包内附十章离线HTML/PDF教程；本地模型快捷连接和评分明细恢复继续保留。

## 使用与升级

安装后打开启动器，点击“启动并打开”，在本机浏览器使用 `http://127.0.0.1:3340/`，不需要软件登录账号。先连接本地模型或配置自己的API，再提交完整稿件。程序内置运行环境，不附带模型权重、密钥或个人稿件。

升级前在原启动器停止服务、关闭启动器，并备份 `%LOCALAPPDATA%\AICounselReview`。安装到原程序目录即可，已有配置、人设和历史保留。源码服务与安装版不要同时占用3340。

[详细使用教程](使用教程-v11.2.md) · [发布与下载](https://github.com/vashzwingli/ai-counsel-review/releases/tag/review-v11.2)

## 预估边界

完播模型 `manuscript-review-v1` 是规则公开的启发式稿面估计，未使用真实账号留存训练。语速与节点时间均为粗估，带状区域是敏感性范围而非统计置信区间；不足以判断时不显示百分比。它复用已有全文审阅依据，不另跑模型重新语义审查每个段落。成片、剪辑与流量会改变结果，作者仍需复核评审意见。

GitHub仓库保持原有权限，上传源码不会自动创建公网网站。MIT及第三方许可证见项目与安装目录。
