# 有来有回的评审 · 2026-10-16

仍用纸面#fffdf5、墨线#252733、桌面#e0e5ec、完成绿#316951和各团既有颜色。主编在上，评论在下，保持1600px/按需详情。人物上方的气泡从单字换成可读短句，12px/1.7；每团按自己的职责显示不同状态，未返回的文案明确标“状态示意”，不称为实时推理。返回后轮播模型实际评论，标“已返回评论”，可跳到评论区。

初稿考虑随机编一句“我发现了一个问题”，会把等待包装成结论，故弃用。气泡轮换只改变呈现，不改变返回状态、百分比或生成内容。减弱动效停止轮播和入场；窄屏改为两列/一列人物，保持气泡可读。

评论仍是模拟观众表达。v6按完整稿件给更多不重复的短评，允许有根据的团内回应，但不伪造真人昵称/赞数/经历。单条短评与对应依据分开；只有有效的、指向同团较早评论的reply_to才显示回应关系，失效引用退回独立评论。新协议兼容旧数组，新增对象comments+dimension_notes，评分计算与权重不变。评分依据按维度展开，旧记录不补造。引文是否存在于原稿给文本匹配标记，匹配不是事实核验。

主编仍独立判断全文，同时必须复核真实收到的各团意见，说明采纳、收窄、不采纳或保留分歧的依据；不能无视评审团，也不能用票数代替原稿证据。新提示仅影响新审稿。
