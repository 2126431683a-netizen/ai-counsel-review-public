# 主编结论置顶 · 2026-10-16

用户认可圆桌动画，希望先看主编结论、下方再看各团；主编仍在实际流程末尾收束，头像在汇总时出现在顶部。侧栏删掉版本、来源和运行缩写等小字。

沿用纸面#fffdf5/底板#e0e5ec/墨线#252733/强调#ffe28a/说明#505362，系统中文字体。主编结论正文17–18px、辅助判断14px；侧栏标题13px、日期11px，不用字号过小的信息。主编是唯一主要视觉焦点，分数仅作辅助。

```
稿件审阅                         实际状态 / 轮次
[主编结论：讨论中为简短占位，汇总时出现头像，返回后显示原文结论]
[展开完整意见 / 评分依据 / 复制]
[圆桌动画：仅在评审团读稿阶段]
各团意见
[五团评分侧重] [筛选与搜索]
[评论流 | 依据与全文关联]
[原稿 / 历轮完整记录]
```

不提前生成结论，不用分数推测主编立场。结论预览取真实主编文本前一至两段，保留Markdown；完整余文按需展开，不重复堆全文。错误/停止/旧记录无结论时明确说明，不假装已经汇总。主编阶段顶部人物与正文占位接替圆桌主编头像，避免同一个主编在两处重复出现。

侧栏只保留新建、搜索、记录标题/日期/当前标记和设置；保留停止与删除确认、可收起工具轨和手机抽屉。来源许可仍在LICENSE等文档中，发行版本校验将侧栏视为可选展示面：不展示时无需硬编码版本，展示但格式/版本错误仍报错。
