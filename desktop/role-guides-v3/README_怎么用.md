# 评论校准v3 使用说明

本版已同步当前本机3340审稿团；刷新页面后开新一轮审稿即可。已有历史报告不会自动重算。

先读00工作说明，再看01–05观众角色和06主编。07可核对评论来源、样本限制和匿名转述。每个观众文件区分观察与设计推断，保留不同需求的反例。

压缩包内“可直接粘贴的系统提示”已把公共说明和角色合并；手动更新时整份复制到对应角色即可。角色配置.json是本项目迁移脚本使用的数据，不是网页原生备份导入格式。不要导入来路不明的凭据备份。

本版只交付并应用角色配置/文档；旧EXE安装包仍保留旧种子。API地址、密钥和原稿不在此包内。原始六份Downloads文件、v1和细读v2均保留。

1008条中含167条UP回复、无信息互动与广告等；不等于1008个有效独立观众。角色是基于公开热门评论的有限校准，不能代替真实观众反馈，也未证明能预测全体观众喜好。
