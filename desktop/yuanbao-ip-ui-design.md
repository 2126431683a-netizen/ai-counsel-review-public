# 源宝墨镜小猫：审稿工作台整体视觉

2026-10-18，用户提供Git源宝IP海报，要求按该形象优化整套UI。该参考替代上一版橙色眼镜猫的品牌外观；各团画像与实际角色设定保留。

## 设计计划

- 纸白 #faf8ee、墨黑 #10110f、源宝黄 #ffd21c、几何蓝 #185bac、朱红 #ed3238、正文灰 #595a50。黑白与黄色为主，蓝/红仅做导航、状态和几何标记。
- 字体继续本机中文无衬线：Microsoft YaHei UI / Noto Sans SC；标题900字重/紧凑字距，正文14–16px，长评论行高1.9，保持可读行宽。少量英文仅品牌Git源宝，界面不复制海报口号。
- 布局：左侧可收起的奶白导航；主区海报式横幅，左侧真正的审稿标题，右侧墨镜小猫与黄圆/蓝块；输入纸面与右侧审阅安排组成一行。模型/角色随后顺序展开。结果页继续主编先结论、五团卡片、评论网格及按需依据。设置页沿用同一边框/色块/排版。

```text
品牌 / 历史 │ 标题与用途                 黄圆＋墨镜小猫
            │ 稿件输入与开始审稿         轮数 / 搜索 / 安排
            │ 本地模型入口与模型指派
            │ 评审团设定
结果        │ 主编结论 → 团分 → 评论 / 点击后的原文依据
```

## 审视与约束

海报辨识度来自墨镜白猫、粗黑轮廓和原色几何，不能只把旧UI换成黄色。主角集中在开场横幅，阅读区域减装饰；去掉大面积灰色内凹阴影，改成2px墨线与短实心错位投影。大标题不挤占输入和开始按钮，不制造无意义英文小字。选择/成功/错误有不同形状和文字，不依赖颜色。移动端输入优先，装饰缩小；长模型名/多团/设置页允许各自滚动。焦点清晰，减少动态偏好沿用。

图像由内置imagegen按用户海报提取成独立透明素材，不将整张海报塞入工作台，不把品牌素材当模型推理或评分依据。仅改变展示与少量引导文案，不改原稿、历史、API、角色提示词、权重或评分算法。新CSS按ip-workspace限定，避免影响非审稿页面；独立预览验证后再构建上线，保留旧懒加载资源。

## 2026-10-18 主编区信息可视化优化

问题：长结论与解释同级、过量加粗、主编原始Markdown中文粗体边界会露出星号，低密度大空白和展开全文造成扫读负担。沿用纸白#faf8ee/墨黑#10110f/源宝黄#ffd21c/蓝#185bac/灰#595a50；字体沿用中文系统无衬线，结论20px、摘要14px/1.8、数据24–36px，正文不靠花式加粗。左侧原文标题＋首段首句，右侧已有总分和五团共用0–10轴横条。下方取主编第一组列表的原话作为关注点，逐条展开，其余全文默认折叠。

```
主编结论                       复制原始意见
原文判断标题  | 五团加权总分 / 同尺度团分条
首句摘要      | 缺分明确留空，禁止按0画分
主编关注点（三项先看，更多展开，每项可看原文）
完整主编意见 / 计算表（按需）
```

审视：无需雷达/饼图或新增优劣档位，避免把主观分包装为客观概率；图表直接用已有report，不改数值/权重。关注点不自动编写优先级、不用计数作严重性。完整原始文字可看可复制，平静阅读样式只移除粗体装饰，代码和原稿不改。小屏上下堆叠、缺分/旧记录保留、键盘展开/焦点可见。

## 2026-10-18 阅卷分数与完播情景

纸白#fffef9、奶白#faf8ee、批注红#bc302a、蓝线#185bac、黄#ffd21c、灰#595a50。沿用中文无衬线正文；右上角原始十分制总分用大号斜体数字与双划线，形成阅卷批注，周围保持安静。布局：主编头像/标题和复制在左，最终分在右；下接现有数据、完播曲线、关注点与完整报告。手机仍保持右上角分数且不遮正文。

审视：真实加权总分必须完整才显示，零分有效，缺分写“待评分”。没有本账号实测留存，不能用6.7分换算67%完播；曲线采用明确标记的可调情景试算，默认参数标“示例”，输入15/20秒留存、时长、后续每分钟流失，公式公开且不改评分。评审依据单独回查原稿逐字匹配引文、展示原段位置，不给曲线伪造精确掉点，不将字数位置冒充秒数。参数只在当前页面内，不写历史/配置，不额外调用模型。需要实际成片同类数据才能校准预测。

方法边界参考：YouTube官方实测留存说明 https://support.google.com/youtube/answer/9314415?hl=en 讨论成片各时点实际观看、跳过与回看；它不提供稿面分到完播率的换算，也不是B站账号训练集。本实现仅透明情景计算：20秒后比例 = 20秒留存 × (1 − 每分钟流失率) ^ 后续分钟数。默认300秒/85%/75%/8%全部是示例假设，不是采样统计、行业均值或置信区间。当前不提供基于文稿自动校准的完播预测。原稿依据是独立复核意见，不改变概率。未来真实同类数据才能用于校准。

## 2026-10-18 自动稿面完播推算（替代手填情景）

用户明确修正：需要基于稿件内容与评审意见自动预估，开头/段落衔接/广告都参与，点击曲线看依据。沿用纸白#fffef9、蓝#185bac、红#bc302a、黄#ffd21c、灰#595a50；普通中文正文12–14px，曲线只强调选中节点。布局：自动预估完播区间/口播时长 → 可点击分段曲线及三类标记 → 当前节点的原文、前后段、各团引文/全文解释 → 折叠计算口径。移除所有手填参数和示例百分比。

审视：使用已完成审阅的分项和可定位引文作启发式推算，不按综合分直接换算、不宣称实测。先识别全文段落、过滤明确镜头备注，按口播字词量估时；开头分影响前20秒，原文对应衔接评价影响该段速度，商业评价仅作用于可定位商业原文或明确推广线索段；自然融入高分增加的阻力较小。相同依据多团采用画像权重平均，不能按重复次数扣减。每个节点保留局部依据与全文参考来源，前后解释可展开；模型意见不能冒充事实。不用关键词自动断言逻辑错误。无足够有效依据不造数。敏感性带是规则/语速变化范围，不是统计置信区间。自动分析只读当前稿件/记录，0新增模型调用，不写历史设置。
