# 评审工作台 · 2026-10-16

用途：让作者先读评审团的评论，再按需核对依据；保留现有稿件、历史、五团权重和模型设置。

设计：深蓝编辑台包裹浅色稿纸工作区。底色深蓝 #102239，稿纸 #F3F6FA，正文 #21354B，分隔 #D8E1EB，重点青绿 #167D8D，待确认赭橙 #AF6039。五团沿用各自颜色作为识别细节，不铺霓虹渐变。字体以本机Microsoft YaHei/PingFang SC等中文无衬线为主，标题28、评论15、说明12，左对齐。

布局：顶部紧凑状态与轮次；五个可点击的评审团评分条构成筛选栏。主区左侧是评论流，右侧是选中评论的审阅依据；原稿、完整报告、费用收在可展开区。小屏改成单列，选中评论后定位到详情，支持键盘和减少动态效果。

```
评审工作台                          第2轮 ▾   评审完成
技术团 分数条 | 实用团 分数条 | 趣味团 | 思考团 | 新手团
全部评审团 / 当前筛选          本轮稿面加权分
评论流（先读反应）            审阅依据（点击后展开）
团名 + 评论                   原文 / 理由 / 限定 / 方向
团名 + 评论                   共用备忘需明确标注
主编意见（独立区域，可展开）   完整原稿/原始报告（按需）
```

复核：本页不是营销首页，不做大字统计英雄区；评分条是实际可交互筛选，不是装饰图表。使用评论流而非整齐摆满同质卡片，右侧证据区服务作者决策。旧记录没有权重时不补造总分，没有逐条理由时明确显示团级共用备忘，不声称展示模型内部思维过程。

新增结构化评论块只提供简短可核对判断摘要，必须与已输出评论原文对应；没有结构化块时解析既有评论/备忘，完整输出始终可查看。所有评分延续reviewScoring，不从共识分推测稿件分。
